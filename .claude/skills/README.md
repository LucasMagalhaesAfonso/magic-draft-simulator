# Custom Skills

Esta pasta contém skills customizados do Claude Code.

## Disponíveis

### `/fix-card`
Corrige bugs de cartas com protocolo de 5 fases.

**Uso**:
```
/fix-card CardName "descrição do erro"
```

**Exemplo**:
```
/fix-card Zurgo "não causa dano ao bloquear"
```

Ver: `fix-card.md` para detalhes completos.
