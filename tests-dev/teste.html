1. Hooks — Automação Determinística

Hooks são scripts que executam automaticamente em eventos específicos do ciclo de vida do Claude Code. Eles são determinísticos, não sugestões.

Evento Quando dispara Uso típico
PreToolUse Antes de rodar uma tool Bloquear comandos perigosos
PostToolUse Após execução Lint, formatter, testes
SessionStart Início da sessão Carregar contexto

Exemplo: Auto-formatar código


{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "prettier --write \"$CLAUDE_FILE_PATHS\""
          }
        ]
      }
    ]
  }
}

2. Agentes e Sub-agentes

Sub-agentes trabalham em contexto separado (até 200k tokens) e retornam apenas um resumo, reduzindo drasticamente o uso de tokens.

Exemplo: Codebase Analyzer


---
name: codebase-analyzer
description: Escaneia o codebase para planejamento.
tools: Read, Grep, Glob
---
Você analisa codebases e retorna planos de implementação.
NUNCA modifique arquivos.

3. Skills

Skills são instruções carregadas automaticamente quando o contexto é relevante. Diferente de slash commands, elas são ativadas pelo Claude.

Exemplo: db-migrations


---
name: db-migrations
description: Regras para migrations de banco
allowed-tools: Bash, Read, Edit
---
SEMPRE use IF NOT EXISTS
NUNCA use DROP TABLE sem confirmação

4. Slash Commands

Comandos manuais invocados com /.


---
name: review
---
Revise o código focando em bugs, segurança e padrões.

5. MCP Servers

MCP conecta Claude Code a serviços externos como GitHub, Postgres, Playwright, Slack e outros. 


{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"]
    }
  }
}

6. Plugins

Plugins agrupam commands, agents, skills, hooks e MCPs em uma unidade instalável.
